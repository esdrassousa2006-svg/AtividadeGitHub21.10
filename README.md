# Meu Projeto de Git e GitHub

##  Sobre o Projeto
Este projeto foi desenvolvido durante as aulas da faculdade, com o objetivo de aprender os principais comandos do Git e a utilização do GitHub.

##  O que estou aprendendo?
- Clonar repositórios do GitHub.
- Criar e modificar arquivos.
- Trabalhar com branches.
- Realizar commits e enviar alterações.
- Resolver conflitos de merge.

##  Objetivo
Desenvolver minhas habilidades em programação, controle de versões e colaboração em projetos.

##  Ferramentas utilizadas
- Visual Studio Code
- Git
- GitHub

---
 Projeto desenvolvido para fins acadêmicos.

 ## Minha experiência com Git e GitHub

Nesta atividade, aprendi a utilizar o Git para
controlar as versões de um projeto.

Também aprendi a criar branches, realizar commits
e trabalhar com diferentes versões de arquivos.

### O que achei da atividade?

Foi uma experiência importante para entender
como os desenvolvedores organizam seus projetos
e trabalham em equipe.
